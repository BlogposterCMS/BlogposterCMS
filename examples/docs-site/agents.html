Working with agents

People and agents work on the same pages and drafts. Clear responsibilities keep changes understandable.

Blogposter CMS · 3 min read

One shared working state

An agent should edit the same content and Designer objects that you see in the CMS. The existing AgentManager exposes current state, stable object IDs and supported actions.

Read first, then edit.

The agent checks the current state and any unsaved changes before modifying a draft.

Write a clear request

Describe the goal, scope and checks you expect. A request for this example could be:

Open the Introduction page in the Docs example.
After the three steps, add a short explanation of the shared layout.

Keep the header, chapter menu and page design unchanged.
Show me the changes before saving.

Review and save deliberately

  1. Read the state: check the page, assigned design and open draft.
  2. Make a focused edit: update the article or the selected Designer object.
  3. Review the result: check content, navigation and appearance.
  4. Save: use the existing save action and verify its confirmation.

Continue working together

You can continue in the same page editor afterwards. These articles are ordinary CMS pages, and their shared frame is an editable Designer document.

For another copy, use Content → Pages → Import example and choose an unused root address. Agents can use the same importer through the Pages surface; importing does not publish content or replace existing pages.
