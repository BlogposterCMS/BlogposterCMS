Layouts & pages

Design the shared parts once. Your pages focus on content and can use an individual design when needed.

Blogposter CMS · 3 min read

One frame for several pages

All three pages in this example use Docs Example · Shared Layout. Changes to its header or chapter menu apply to every page using it.

Layout and content stay separate.

This article belongs to the “Layouts & pages” page. Its text is not embedded in the shared design.

The container for your content

The docs-demo-content container is marked as the page-content area. It sits beside the chapter menu, grows with the article, and keeps the footer below the content.

Combine vertical and horizontal containers in the Designer: a header at the top, navigation and content side by side, and a footer underneath.

Three choices for each page

  1. Main design + content: the page uses the website's shared frame.
  2. Main design + own design + content: an individually designed page remains inside the website frame.
  3. Own design + content: the page uses an independent complete frame.

This example uses the third option with the same Docs design assigned to every chapter. It does not change your website's main design or home page.

Try it yourself

Open Content → Pages. Edit an article in the page editor and open its shared design in Design Studio. Select the menu or breadcrumb and use the Content tab to configure it. Use Edit menu links to manage chapter labels and destinations.

Imported examples start as drafts. Review and publish the shared design in Studio, then publish each page when you want it to be visible. Nothing is installed automatically.

The “On this page” and previous/next links in these sample articles are authored content. Update them when you change headings or chapter order.
